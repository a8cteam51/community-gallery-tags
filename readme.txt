Allow your users to upload photos and tag them

== Description ==

This plugin allows authenticated users to upload images to your WordPress site, which are displayed in a Gallery.
It also gives users the ability to tag the any photos in the Gallery.

The tags are added to the Media images as a custom people taxonomy. All tags added to images must be approved in the WP Admin
before they appear on the site.

Clicking on a tag leads to a people archive page which displays all the images with that Tag.

Multiple Galleries can be added to the site. Only images attached to the viewed page will display in that Gallery.

== Installation ==

This section describes how to install the plugin and get it working.

e.g.

1. Upload the plugin files to the `/wp-content/plugins/community-gallery-tags` directory, or install the plugin through the WordPress plugins screen directly.
1. Activate the plugin through the 'Plugins' screen in WordPress
